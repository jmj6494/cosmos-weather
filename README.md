# COSMOS WEATHER

도시 이름을 넣으면 그 도시의 날씨를 보여주는 웹 페이지입니다.
파일 하나(`index.html`)로 되어 있고, 따로 설치할 것이 없습니다.

AI 협업 코딩(바이브 코딩)으로 만들었습니다. 코드는 AI와 같이 썼고,
무엇을 보여줄지 정하고 결과를 확인하는 건 제가 했습니다.
제가 AI와 함께 만든 첫 결과물입니다.

## 무엇이 나오나

- 지금 기온과 날씨, 습도, 바람
- 미세먼지·초미세먼지 수치와 좋음 / 보통 / 나쁨 표시
- 지금부터 24시간 예보 (3시간 간격) + 비 올 확률 그래프
- 5일 예보 (최고·최저 기온, 비 올 확률)

날씨에 따라 화면 강조색이 바뀝니다. 맑으면 노랑, 비가 오면 하늘색 같은 식입니다.

## 실행하는 법

날씨 데이터는 OpenWeather에서 받아옵니다. **키를 직접 발급받아 넣어야 합니다.**

1. [openweathermap.org](https://openweathermap.org/api) 에서 무료 키를 발급받습니다
2. `index.html` 을 열어 아래 줄을 찾습니다

   ```js
   const API_KEY = "";
   ```

3. 따옴표 안에 발급받은 키를 넣고 저장합니다
4. `index.html` 을 더블클릭해서 엽니다

키를 안 넣어도 페이지는 열립니다. 실제 날씨 대신 샘플 데이터가 나옵니다.

## 키를 저장소에 안 넣어 둔 이유

이 페이지는 브라우저에서만 도는 코드라서 **키를 숨길 방법이 없습니다.**
저장소에 올리지 않아도, 배포해서 누가 열면 개발자 도구에서 그대로 보입니다.

그래서 저장소에는 빈 칸으로 두고, 쓰는 사람이 자기 키를 넣도록 했습니다.
진짜로 숨기려면 서버를 하나 두고 거기서 대신 호출해야 하는데,
그건 아직 제가 못 해서 다음에 해 볼 생각입니다.

## 만들면서 막혔던 것

**한글로 "서울"을 치면 잘 안 찾아졌습니다**
날씨 API가 한글 도시 이름을 제대로 못 알아들을 때가 있었습니다.
→ 서울→Seoul, 평택→Pyeongtaek처럼 주요 도시 32곳을 영어 이름으로 바꿔 주는 표를 넣었습니다.
표에 없는 이름은 입력한 그대로 보냅니다.

**날씨 설명이 "실 비"처럼 이상하게 나왔습니다**
API가 주는 한글 설명에 띄어쓰기가 이상하게 섞여 있었습니다.
→ 날씨마다 붙어 있는 번호(코드)를 기준으로 "약한 비", "구름 많음" 같은 설명을
직접 정리해서 그걸 먼저 씁니다.

**밤 늦게 열면 시간별 예보가 한 칸만 나왔습니다**
처음엔 '오늘 날짜'에 해당하는 칸만 골라서 보여줬습니다.
그러니까 자정 가까이 되면 남은 칸이 거의 없었습니다.
→ 날짜로 자르지 않고, 지금부터 8칸(24시간)을 그대로 보여주도록 바꿨습니다.

## API를 처음 써 보면서 알게 된 것

API는 다른 서비스한테 데이터를 달라고 요청하는 주소라는 걸 이걸 만들면서 알았습니다.
주소 뒤에 도시 이름이랑 키를 붙여서 보내면 날씨 데이터가 돌아옵니다.

요청은 3번 보냅니다.

1. 도시 이름으로 **현재 날씨**를 받습니다. 여기에 그 도시의 위도·경도가 같이 들어 있습니다
2. 그 위도·경도로 **미세먼지**와 **5일 예보**를 받습니다.
   두 개는 서로 기다릴 필요가 없어서 `Promise.all` 로 동시에 요청합니다
